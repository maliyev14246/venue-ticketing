# Solstice Game Showcase - Venue Ticketing

WM1 (INFT 2302) Interactive Venue Ticketing System.

A ticket-selection website for a summer game showcase held in an auditorium-style hall.
Prices are in US dollars.

Zones: Premiere Pit ($180), Main Floor ($120), Sunset Terrace ($85), Skyline Balcony ($45).

Users can inspect a seat, add it to the cart, remove it, and the cart is saved in localStorage.
The map has zoom, move and reset buttons, plus mouse-wheel zoom and drag.

To run: open index.html in a browser.
